# AI 文本工具站 — 开发计划与规范

- **文档版本**：v1.0
- **日期**：2026-09-22
- **前置阅读**：01-PRD、02-技术架构

---

## 1. 总原则

- **8 周上线**，每周有可见交付物，不追求完美，上线优先
- 单人开发，规范从简但必须守：commit 可读、环境变量集中、每个外部依赖可替换
- 每周产出一次 build 部署到预览环境（Cloudflare Pages preview），从第 2 周起网站就应"活着"

## 2. 八周里程碑

### 第 1 周 — 骨架与纯客户端工具

- 4 个纯客户端工具：word-counter、case-converter、remove-line-breaks、text-sorter
- 部署到 Cloudflare Pages 预览域名

### 第 2 周 — 检测器核心链路
- D1/KV 绑定与 0001 迁移
- Turnstile 集成 + 限流中间件（enforceQuota）
- 检测 provider 抽象层 + 接入第一家供应商

- **交付物**：检测器全流程可用（匿名额度生效）

### 第 3 周 — 人性化核心链路

- `/ai-humanizer` 四模式、对比视图、强度滑杆
- 闭环模块（前/后检测分展示）
- `/paraphrasing-tool`、`/text-summarizer`（复用 llm.ts）
- **交付物**：两大核心工具闭环打通，矩阵工具满 8 个

### 第 4 周 — 账户与支付
- 魔法链接（Resend 发信 + verify + session）
- Stripe：产品/价格、Checkout、Customer Portal、Webhook 验签与状态同步
- PaywallModal + UsageMeter + `/account` + `/pricing`
- **交付物**：能收到真钱（用 Stripe 测试模式自付一单走完全流程）

### 第 5 周 — pSEO 引擎
- `data/longtail-seeds.csv` 建表 60 条（写法见 05 手册）
- `scripts/generate-longtail.ts` 生成器（模板 × 变量 → .astro 页面，构建时执行）
- sitemap.xml 自动包含全部页面
- **交付物**：站点从 15 页膨胀到 75+ 页，全部真实可用

### 第 6 周 — 内容与 GEO 合规
- 8 篇博客（选题清单见 05 手册 §6）
- llms.txt、robots.txt（放行 AI 爬虫）、JSON-LD 结构化数据
- OpenGraph 图（用免费工具批量生成，不外包）
- **交付物**：GEO 清单全绿

### 第 7 周 — 打磨与观测
- 性能预算核查（02 文档 §11），超预算页面减肥
- 4 个埋点事件接通 + 简易周报查询（直接查 D1 的 SQL 脚本）
- 错误兜底：DETECTOR_BUSY 友好降级、Stripe 失败路径、Resend 超时
- 移动端适配过一遍（60%+ 流量来自手机）
- **交付物**：上线候选版

### 第 8 周 — 上线

- **交付物**：正式站上线，开始 SEO 计时

## 3. 开发规范

### 3.1 Git

- 分支：`main`（生产，push 即部署）+ 功能分支 `feat/xxx`（短命，合并即删）
- Commit 格式：`type(scope): message`，type ∈ feat / fix / chore / docs / seo
  - 例：`feat(detector): sentence-level highlighting`
- 每周五打 tag `v0.x`，方便回滚

### 3.2 代码

- TypeScript strict 模式；禁 `any`（确需时 `// eslint-disable-next-line` 注明原因）
- 命名：组件 PascalCase；工具函数 camelCase；环境变量 SCREAMING_SNAKE
- 一个工具 = `pages/` 下一个 .astro 壳 + `components/tools/` 一个 island 组件 + 必要时 `lib/` 一个纯逻辑文件，三处同名对齐
- 样式只用 Tailwind 原子类 + 少量全局 css；不引入第二个 CSS 方案
- 外部 API 调用一律 try/catch 并转为统一错误码（02 文档 §5）

### 3.3 环境变量（三处同步维护：.dev.vars / Pages 控制台 / 文档清单）

| 变量 | 用途 |
|---|---|
| `DETECT_PROVIDER` / `DETECT_API_KEY` | 检测供应商与密钥 |
| `DEEPSEEK_API_KEY` | 人性化 LLM |
| `PAY_PROVIDER` / 对应 API 密钥 / 产品 ID ×2 | 支付（MoR 优先：FastSpring/Creem 支持中国大陆个人；Stripe 需先注册美国 LLC，见 04 文档 §5）|
| `RESEND_API_KEY` / 邮件发件域名 | 魔法链接 |
| `TURNSTILE_SECRET_KEY` | 人机验证 |
| `AUTH_SALT` | 匿名指纹加盐 |

### 3.4 质量底线

- prompts.ts 任何修改必须跑样本回归集（20 条），AI 分下降幅度不得劣化
- 支付与额度逻辑（quota.ts / stripe.ts）改动必须手测三条路径：匿名耗尽、免费升级、Pro 续费
- 每次部署后跑一遍冒烟脚本（curl 四个端点 + 打开首页）

## 4. 上线后迭代节奏（第 3-12 个月）

| 频率 | 动作 |
|---|---|
| 每周 | 看 Search Console：新页收录数、展现、点击；加 5-10 个长尾页 |
| 每两周 | 一个新矩阵工具或一个既有工具增强 |
| 每月 | 成本核对（§02-9 红线公式）；样本回归集扩充 5 条；竞品扫一遍（同类站新词、新功能）|
| 每季 | 评估 V1.1：API 开放、多语言界面、检测供应商切换 |

- **项目代号**：ai-text-tools
- **文档版本**：v1.0
- **日期**：2026-09-22
- **状态**：已定稿，可进入开发

---

## 1. 项目概述

### 1.1 一句话定义

面向英语市场的 AI 文本工具网站：以 **AI 检测器**与 **AI 人性化工具**为核心付费功能，以 15-20 个免费文本小工具和长尾落地页矩阵为流量入口，通过"免费限额 + Pro 订阅（$4.99/月）"变现，参考 TinyWow 商业模式。

### 1.2 商业逻辑

> 检测器制造焦虑，人性化工具贩卖解药，小工具引来人流，长尾页铺开网面，订阅把一切变现。

### 1.3 核心约束（决定一切设计决策）

| 约束 | 含义 |
|---|---|
| **预算 ≈ $15** | 域名 $10/年 + Chrome 等杂费。固定成本必须为 $0，所有第三方服务只用免费层或纯抽成模式 |
| **一人开发** | 所有功能必须单人可维护，拒绝重型架构 |
| **6-12 个月见收入** | 前 3 个月为 SEO 爬坡期，收入预期为 0，产品按此节奏设计 |

### 1.4 成功指标（North Star）

| 阶段 | 时间 | 目标 |
|---|---|---|
| 验证期 | 上线后第 3 个月 | 月自然访问 ≥ 10,000；索引页面 ≥ 100 |
| 增长期 | 第 6 个月 | 月访问 30,000+；Pro 付费用户 ≥ 100（MRR ≥ $400）|
| 站稳期 | 第 12 个月 | 月访问 80,000+；MRR ≥ $1,500 |

## 2. 用户画像

| 画像 | 核心诉求 | 使用路径 | 付费动机 |
|---|---|---|---|
| **学生**（流量最大）| 论文/作业过检测 | 搜 "humanize AI text for essays" → 人性化 → 检测验证 | 免费次数用完、赶 deadline |
| **内容写手 / SEO 从业者** | 交付的稿子不被判 AI、不被 Google 降权 | 搜 "AI detector for SEO content" → 检测 → 人性化 | 批量处理、长文限制 |
| **教师 / 编辑** | 判断稿件是否 AI 代写 | 搜 "AI detector for teachers" → 批量检测 | 长文、批量、报告 |
| **非英语母语职场人** | 邮件/帖子写得自然 | 搜 "email tone changer" → 改写/语调工具 | 顺带转化，贡献小 |

设计含义：**页面文案优先服务前三类**，第四类由矩阵工具承接。

## 4. 功能需求详述

### 4.1 AI 检测器 `/ai-detector`

**输入**：粘贴文本（textarea）；支持拖入 .txt 文件。

**处理**：≥ 50 词才可提交（低于下限提示"Text too short"）；Turnstile 人机验证。

**输出**（结果区，无页面跳转）：
1. **总分**：AI Probability 0-100%，大字号 + 环形进度
2. **结论标签**：Human (< 40%) / Mixed (40-70%) / AI-Generated (> 70%)
3. **逐句高亮**：句子按 AI 嫌疑度标红（高）/黄（中）/绿（低），可点击跳转原文
4. **元信息**：词数、句数、检测耗时
5. **分享按钮**：生成只读结果页 `/r/<id>`（可被搜索引擎收录 = 免费 UGC 页面）
6. **转化钩子**：当总分 > 70%，结果区显示"Make it sound human →"按钮跳转人性化页并自动带上文本（**这是全站最重要的转化路径**）

**额度**：

| 用户 | 限制 |
|---|---|
| 匿名 | 5 次/天（IP+指纹计数），单次 ≤ 500 词 |
| 已登录免费 | 10 次/天，单次 ≤ 1,500 词，保留最近 20 条历史 |
| Pro | 无限次，单次 ≤ 30,000 词，完整历史，批量检测（≤ 10 文件/次）|

### 4.2 AI 人性化工具 `/ai-humanizer`

**输入**：粘贴文本；选择模式。

**模式（4 种）**：
- Standard：通用改写
- Academic：学术语域，保留术语与引用结构
- Casual：口语化
- Creative：表达多样化，允许更大的改写幅度

**输出**：
1. 改写后文本（可一键复制）
2. **前后对比视图**（side-by-side，差异高亮）
3. **闭环验证模块**（杀手锏）：显示"人性化前 AI 分 → 人性化后 AI 分"，内部自动跑一次检测
4. 改写强度滑杆（Light / Balanced / Strong）

**额度**：

| 用户 | 限制 |
|---|---|
| 匿名 | 3 次/天，单次 ≤ 300 词 |
| 已登录免费 | 5 次/天，单次 ≤ 800 词，仅 Standard 模式 |
| Pro | 无限，单次 ≤ 10,000 词，全模式，批量（≤ 5 段/次）|

### 4.3 账户系统

- **免注册使用**是默认体验（SEO 流量转化第一原则）
- 登录方式：**邮箱魔法链接**（唯一方式，V1 不做 Google OAuth，降低依赖）
- 登录入口出现在：额度用尽时、历史记录入口、订阅入口
- 账户页 `/account`：历史记录、用量、订阅管理（跳转 Stripe 门户）

### 4.4 订阅与支付

- **定价**：Pro $4.99/月，$39/年（年费锚定，首屏突出"Save 35%"）
- **支付**：Stripe Checkout（托管页，不做自建支付表单）
- **入口**：额度耗尽弹层（主转化点）、定价页、工具页顶部常驻升级条
- **续费/退订**：全部交给 Stripe Customer Portal，不自建
- **Webhook**：`checkout.session.completed`、`customer.subscription.updated/deleted` 同步订阅状态

### 4.5 防滥用（成本生命线）

免费额度 = 真金白银的 API 成本，必须层层设防：

1. **Cloudflare Turnstile**（免费）挂在所有调 LLM/检测 API 的提交按钮上
2. 匿名额度按 **IP + 浏览器指纹** 双重计数（KV 存储，24h 滚动窗口）
3. 单次请求硬上限：检测 30,000 词 / 人性化 10,000 词（服务端再校验一次，前端限制仅为体验）
4. 异常速率（同 IP > 30 次/小时）自动拉黑 24h
5. 分享结果页静态化，不消耗 API

### 4.6 非功能需求

| 项 | 要求 |
|---|---|
| 性能 | 工具页 LCP < 1.5s，纯客户端工具页 JS 包 < 50KB；默认零 JS，仅工具岛按需水合 |
| 隐私 | 明示"文本仅用于处理，不存储原文"（检测结果只存分数与句子偏移，不存文本本身）；Privacy Page 写清 |
| SEO | 每页独立 title/description/canonical/OG；全站 sitemap.xml 自动生成；详见 05 手册 |
| 浏览器兼容 | 最近两个大版本的 Chrome/Safari/Firefox/Edge；不支持 IE |
| 语言 | 站点 UI 英文；V1 不做多语言界面（长尾页的局部本地化除外）|

### 4.7 V1 明确不做（范围纪律）

- ❌ 抄袭检测（plagiarism）— API 贵、法律复杂
- ❌ PDF / 图片 / 视频工具 — TinyWow 地盘，红海
- ❌ 自研检测模型 — 永远接第三方
- ❌ 移动 App、团队版、API 开放 — 等月收入 > $500 再议
- ❌ 自建评论/社区功能

## 5. 数据埋点（最少集）

只用 Cloudflare Web Analytics + 4 个自定义事件（写入 D1，自己查）：

| 事件 | 触发点 | 用于 |
|---|---|---|
| `tool_used` | 每次工具执行（含 tool 名、是否匿名）| 判断哪些工具值得加码 |
| `share_created` | 生成分享页 | 传播监测 |
| `paywall_hit` | 额度耗尽弹层展示 | 转化漏斗 |
| `checkout_started` | 跳转 Stripe | 转化漏斗 |

漏斗：`tool_used → paywall_hit → checkout_started → 订阅成功`，每周看一次比率。

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| 检测 API 成本失控 | 额度分层 + Turnstile + 服务端硬上限；检测 provider 做成可替换抽象层（见技术文档）|
| 竞品涌入、窗口收窄 | 打长尾覆盖面，不打大词；每月新增页面是核心 KPI |
| Google 惩罚批量页 | 每页必须真实可用 + 针对性文案；宁可 50 好页不要 500 垃圾页 |
| 前 3 个月零收入心理压力 | 成功指标已按此设定；期间唯一 KPI 是索引页面数与周访问增速 |
| 检测准确性质疑/投诉 | 页面明示"概率参考，非定论"的免责说明；FAQ 引导合理使用 |

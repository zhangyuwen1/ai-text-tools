## 1. 技术选型及理由

| 层 | 选型 | 理由 | 免费额度 |
|---|---|---|---|
| 框架 | **Astro 5** + `@astrojs/cloudflare` 适配器 | 默认零 JS、 Islands 架构最适合工具站 SEO；一个仓库同时产出静态页 + API 端点 | — |
| UI | 原生 TS + 轻量组件（Preact islands） | 拒绝 React 全家桶，JS 包预算 < 50KB/页 | — |
| 样式 | Tailwind CSS | 快，且与 Astro 生态契合 | — |
| 托管 | **Cloudflare Pages** | 免费层无限带宽静态 + Functions；与 D1/KV/Turnstile 同平台 | 静态无限；Functions 10 万请求/天 |
| 数据库 | **Cloudflare D1**（SQLite）| 免费层 5GB，够用两年；与 Workers 同运行时 | 500 万行读/天 |
| KV | **Cloudflare KV** | 匿名限流计数、缓存检测结果指纹 | 10 万读/天 |
| 人机验证 | **Cloudflare Turnstile** | 免费，体验好于 reCAPTCHA | 无限 |
| 邮件 | **Resend** | 魔法链接发送 | 3,000 封/月（100/天）|
| 支付 | **Stripe**（Checkout + Customer Portal + Webhook）| 纯抽成无月费，托管页省掉全部支付开发 | 2.9% + $0.30/笔 |
| LLM（人性化）| **DeepSeek API**（主力）/ Gemini（备）| 人性化对模型要求不高，DeepSeek 成本最低；抽象层可切换 | 按量，极低 |
| AI 检测 | **第三方检测 API**（见 §6 抽象层）| 不自研模型 | 按量（成本控制见 §9）|
| 统计 | Cloudflare Web Analytics + D1 自埋点 | 免费、无 cookie 弹窗烦恼 | — |

**总固定成本：$0/月。** 唯一现金支出为域名 ~$10/年。

```

                         │            Cloudflare Pages              │
   用户浏览器 ──HTTPS──▶  │  ┌──────────────┐   ┌─────────────────┐  │
                         │  │  静态资源(SPA │   │  Server 端点      │  │
                         │  │  工具页/长尾页/│   │  /api/detect     │  │
                         │  │  博客/分享结果页)│  │  /api/humanize   │  │
                         │  └──────────────┘   │  /api/auth/*     │  │
                         │                     │  /api/stripe/*   │  │
                         │                     │  /api/event      │  │
                         │                     └───────┬─────────┘  │
                         │            ┌────────────────┼─────────┐  │
                         │            ▼                ▼         ▼  │
                         │      ┌─────────┐    ┌──────────┐ ┌─────┐ │
                         │      │ D1 (SQLite)│   │ KV(限流/缓存)│ │Turnstile│ │
                         │      └─────────┘    └──────────┘ └─────┘ │
                         └──────────┬───────────────────┬───────────┘
                                    │                   │
                       ┌────────────▼──────┐   ┌────────▼─────────┐
                       │  检测 Provider     │   │  LLM (DeepSeek)   │
                       │  (可替换抽象层)     │   │  人性化/改写/摘要  │
                       └───────────────────┘   └──────────────────┘
                                    ▲
                       ┌────────────┴───────────────┐
                       │  Stripe Webhook（回调入 D1）│
                       │  Resend（魔法链接邮件）      │
                       └────────────────────────────┘
```

**关键原则**：
1. 纯客户端工具（word counter 等）**不经过任何服务端**——零成本、零延迟
2. 服务端端点只做三件事：鉴权/限流 → 调外部 API → 记账
3. 检测与 LLM 均为可替换抽象层，供应商变更不改业务代码

## 4. 数据库设计（D1 / SQLite）

```sql
-- migrations/0001_init.sql
CREATE TABLE users (
  id           TEXT PRIMARY KEY,            -- nanoid
  email        TEXT NOT NULL UNIQUE,
  plan         TEXT NOT NULL DEFAULT 'free', -- free | pro
  stripe_customer_id TEXT,
  created_at   INTEGER NOT NULL
);

CREATE TABLE sessions (
  token        TEXT PRIMARY KEY,            -- 随机 32B hex
  user_id      TEXT NOT NULL REFERENCES users(id),
  expires_at   INTEGER NOT NULL
);

CREATE TABLE magic_links (
  token        TEXT PRIMARY KEY,
  email        TEXT NOT NULL,
  expires_at   INTEGER NOT NULL,            -- 15 分钟有效
  used         INTEGER NOT NULL DEFAULT 0
);

CREATE TABLE subscriptions (
  id           TEXT PRIMARY KEY,            -- stripe subscription id
  user_id      TEXT NOT NULL REFERENCES users(id),
  status       TEXT NOT NULL,               -- active | canceled | past_due
  price        TEXT NOT NULL,               -- monthly | yearly
  current_period_end INTEGER NOT NULL
);

CREATE TABLE usage_events (                 -- 登录用户用量 + 埋点合表
  id           TEXT PRIMARY KEY,
  user_id      TEXT,                        -- 匿名为 NULL
  anon_key     TEXT,                        -- 匿名指纹 hash
  kind         TEXT NOT NULL,               -- detect | humanize | paraphrase | summarize | share | paywall_hit | checkout_started
  meta         TEXT,                        -- JSON：{mode, words, score...}
  created_at   INTEGER NOT NULL
);

CREATE INDEX idx_usage_user_time ON usage_events(user_id, created_at);
CREATE INDEX idx_usage_anon_time ON usage_events(anon_key, created_at);

CREATE TABLE detection_results (            -- 分享页数据；只存分数与偏移，不存原文
  id           TEXT PRIMARY KEY,            -- 短 ID，用于 /r/<id>
  score        REAL NOT NULL,
  sentences    TEXT NOT NULL,               -- JSON: [{offset,len,flag}]
  words        INTEGER NOT NULL,
  created_at   INTEGER NOT NULL
);
```

**隐私承诺的技术兑现**：`detection_results` 表**不存原文文本**，只存句子偏移量与分数；`usage_events` 只存元信息。人性化请求处理完即弃，不落库。

## 5. API 设计

所有端点均为 JSON in/out，错误统一格式：`{ "error": { "code": "RATE_LIMITED", "message": "..." } }`

### 5.1 `POST /api/detect`

```jsonc
// 请求
{ "text": "...", "turnstileToken": "..." }
// 响应
{ "score": 0.87, "label": "ai", "words": 412,
  "sentences": [ { "offset": 0, "len": 64, "flag": "high" }, ... ],
  "shareId": "xK3pQ9" }
```

服务端流程：Turnstile 校验 → 限流（§7）→ 文本长度校验（50–30000 词）→ provider.detect() → 写 usage_events → 若分数 > 0.7 附带 `humanizeUrl`。

### 5.2 `POST /api/humanize`

```jsonc
// 请求
{ "text": "...", "mode": "standard", "strength": "balanced", "turnstileToken": "..." }
// 响应
{ "result": "...", "beforeScore": 0.91, "afterScore": 0.06 }
```

`afterScore` 由服务端在人性化完成后自动跑一次轻量检测得到（闭环数据）。成本注意：此端点一次请求消耗 1×LLM + 1×检测，额度门槛必须严格执行。

### 5.3 认证三件套

- `POST /api/auth/magic-link`：`{email}` → 生成 15 分钟一次性 token，Resend 发信（每日每 IP 限 3 封）
- `GET /api/auth/verify?token=...`：校验 → 建 session → Set-Cookie（HttpOnly, Secure, SameSite=Lax）→ 302 到来源页
- `POST /api/auth/logout`：删 session 清 Cookie

### 5.4 Stripe

- `POST /api/stripe/checkout`：`{plan: 'monthly'|'yearly'}` → 创建 Checkout Session（含 `client_reference_id=userId`）→ 返回 url
- `POST /api/stripe/webhook`：验签 → 处理 `checkout.session.completed`（写 users.plan=pro + subscriptions）、`customer.subscription.updated/deleted`（同步状态）

## 6. 检测 Provider 抽象层

```typescript
// src/lib/detect/types.ts
export interface DetectResult {
  score: number;               // 0..1 AI 概率
  sentences: { offset: number; len: number; flag: 'high'|'mid'|'low' }[];
}
export interface DetectorProvider {
  name: string;
  detect(text: string): Promise<DetectResult>;
}
```

实现顺序（供应商按成本/可得性择一接入，接口不变）：

1. **V1 首选**：付费检测 API（按 credit 计费类，如 Originality 类服务的 API）——准确率最好，按量付费与免费额度对齐
2. **兜底**：开源方案自部署（Binoculars 类模型跑在按小时计费的 GPU 或 Serverless GPU 上，只在请求时唤醒）——单位成本更低，V1.1 再切
3. **工厂**：`getDetector()` 读环境变量 `DETECT_PROVIDER` 返回实现，切换供应商 = 改一个 env

**降级策略**：provider 超时/报错时返回 `{error: {code: 'DETECTOR_BUSY'}}`，前端展示友好重试提示并**不计入用户额度**。

## 7. 限流设计（KV）

```
Key 结构            值              TTL
rl:anon:{fp}:{ymd}  累计次数         至当日结束
rl:ip:{ip}:{ymd}    累计次数（防指纹伪造）至当日结束
rl:blk:{ip}         1               24h（触发阈值 30/h 时写入）
```

- 匿名：`anon_key = sha256(fp + ip + 秘盐)`，fp 用 canvas/UA/语言组合的弱指纹即可（不追求强对抗，Turnstile 已挡住绝大多数脚本）
- 登录：查 `usage_events`（`user_id + kind + 今日`计数），Pro 直接放行但仍记 usage 供成本核算
- 所有 API 端点入口处统一 `enforceQuota()`，返回剩余次数供前端 UsageMeter 渲染

## 8. 人性化提示词工程（`src/lib/prompts.ts` 核心资产）

```
SYSTEM: You rewrite AI-generated text so it reads as natural human writing.
Rules:
1. Vary sentence length aggressively; mix short punchy sentences with longer ones.
2. Remove AI-typical words: delve, moreover, tapestry, landscape, foster,
   utilize, "In conclusion", "It's important to note".
3. Keep ALL facts, numbers, names and meaning intact. Never add information.
4. Match the requested register: {mode}. Strength of rewrite: {strength}.
5. Output ONLY the rewritten text, no preamble.
USER: {text}
```

- 四模式 = 不同 register 描述片段；三档强度 = 改写指令强度
- 参数：DeepSeek `temperature 0.9`（多样化），`max_tokens = 输入词数 × 2.5`
- **回归测试**：维护 20 条样本集（各类文风），每次改 prompt 跑一遍，对比"AI 分下降幅度 + 事实保真"两个指标，防止改坏

## 9. 成本控制模型（本站的生死线）

单次成本（估算，以接入时实际价为准）：

| 操作 | 成本 | 谁承担 |
|---|---|---|
| 检测一次（500 词）| ~$0.005–0.02 | 免费/付费用户均摊 |
| 人性化一次（300 词，DeepSeek）| ~$0.001 | 同上 |
| 人性化闭环（含二次检测）| 检测成本 ×2 | 同上 |

**红线公式**：`日免费额度总成本 ≤ 日 Pro 收入 × 0.5`。运营初期检测供应商按量计费无月费，但必须每周核对：

- 若免费用户日耗 > $3 且 MRR 为 0 → 收紧匿名额度（5→3 次/天）
- Turnstile 失效风险（脚本绕过）→ 监控同 IP 小时频次，自动进黑名单（§7）

**目标单位经济**：Pro 用户月费 $4.99，其 API 消耗必须 < $1/月（靠 30k 词上限与正常使用频率天然约束）。

## 10. 安全清单

- [ ] 所有 API 端点：Turnstile + 限流 + 输入长度硬校验三连
- [ ] Stripe webhook 必须验签（`stripe.webhooks.constructEvent`）
- [ ] Session Cookie：HttpOnly + Secure + SameSite=Lax；30 天过期
- [ ] 魔法链接：一次性（used 标记）、15 分钟过期、每日每 IP 3 封
- [ ] 分享页 `/r/<id>`：只读静态，无脚本执行面（文本本就不存）
- [ ] CSP 响应头：`default-src 'self'`，AdSense/Stripe 域名单独放行
- [ ] D1 不存用户原文（隐私承诺，见 §4）
- [ ] `.dev.vars`（本地秘钥）与 wrangler secrets 分离，不入 git

## 11. 性能预算

| 页面类型 | JS（gzip） | LCP 目标 |
|---|---|---|
| 纯客户端工具页 | < 30KB（Preact island + 工具逻辑）| < 1.2s |
| 检测/人性化页 | < 60KB | < 1.5s |
| 长尾页/博客 | < 5KB（几乎纯 HTML）| < 1.0s |

手段：Astro 零 JS 默认 + island 按需加载；字体用系统字体栈（连 Google Fonts 都不请求——速度即 GEO 优势）；检测结果接口响应 < 10s（超时友好提示）。
